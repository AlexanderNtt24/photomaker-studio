# PhotoMaker Studio — план

Локальное приложение для macOS (веб-приложение внутри `.app`) для подгонки фото под печатные форматы и сборки коллажей на листе A4. Работает офлайн, интерфейс на русском, тема как в системе.

Статус: этапы 1–4 (MVP: каркас, подгонка, эффекты и пресеты, undo/redo, экспорт PNG, сборка `.app`) реализованы по `docs/superpowers/plans/2026-11-15-plan-1-fit-mode-mvp.md`. Дальше: режим «Коллаж» и PDF (План 2), стикеры, текст и проекты (План 3).

## 1. Решения

| Тема | Решение |
|---|---|
| Платформа | Веб-приложение (React + Vite + TypeScript) в обёртке `.app` |
| Обёртка | Electron (не требует Rust; Tauri можно рассмотреть позже, если важен размер) |
| Офлайн | Да, никаких внешних запросов |
| Язык / тема | Русский / системная (`prefers-color-scheme`) |
| Интерфейс | Минималистичный, два режима в боковой панели или вкладках |
| Ввод | Drag & drop и диалог выбора файла; JPG, PNG, WebP, HEIC/HEIF (iPhone) |
| Вывод | PNG; печать на A4 несколькими снимками на листе |
| Разрешение | 300 dpi по умолчанию, настраивается; предупреждение, если исходник мал для печати |
| Проекты | Сохранение и открытие проекта коллажа (`.pmstudio`, JSON + ссылки/встроенные изображения) |
| Undo/redo | Обязательно, во всех режимах |
| Git | Репозиторий обязателен (локально сразу; публикация на GitHub — по твоей команде) |

## 2. Режим 1 — «Подгонка под размер»

- Форматы (см): 9×13, 10×15, 13×18, 15×21 (A5), 20×30, 21×30 (A4), 10×10, 3×4 (паспорт) + свой размер в см или мм.
- Ориентация: книжная / альбомная, переключатель.
- Способ подгонки:
  - **Кроп** — рамка нужного соотношения, двигать и масштабировать фото под ней.
  - **Вписать** — фото целиком, поля заданного цвета (белый по умолчанию).
- Эффекты и пресеты (раздел 4) применяются к фото.
- Проверка разрешения: считать эффективный dpi по обрезке и размеру печати, предупреждать при < 300 (мягкое) и < 150 (сильное).
- Пакетная обработка: добавить несколько фото, выбрать один формат и способ, экспортировать все PNG в выбранную папку.
- Экспорт: PNG, размер в пикселях = см × dpi / 2.54.

## 3. Режим 2 — «Коллаж»

- Лист: A4 (книжный/альбомный), фон: цвет, градиент или текстура (в том числе тёмный, как на брошюре).
- Два способа:
  - **Шаблоны-сетки:** 2, 3, 4, 6 фото, плюс листы «несколько одинаковых снимков» (например, 4 × 10×15 на одном A4; 2 × 13×18; 8 × 9×13 и т.д.), с метками обрезки по желанию.
  - **Свободный макет (скрапбукинг):** перемещение, масштаб, поворот, порядок слоёв.
- Для каждого фото: рамка/паспарту (цвет, толщина), тень, скругление углов, поворот, индивидуальные эффекты и пресеты.
- Текст: подписи с выбором шрифта (системные + пара рукописных), размер, цвет, поворот.
- Стикеры и декор: стартовый набор (ленты/скотч, стрелки, ракушки, звёзды, рамки, штампы) в виде SVG/PNG в папке `assets/stickers/`. Загрузка своих стикеров через импорт; в будущем — пакеты стикеров папкой.
- Экспорт: PNG листа в 300 dpi (A4 = 2480×3508 px), опционально PDF позже.
- Сохранение/открытие проекта.

## 4. Эффекты и пресеты

- Корректировки: яркость, контраст, насыщенность, резкость, размытие, виньетка, зерно.
- Фильтры: ч/б, сепия, винтаж.
- Пресеты: набор встроенных (комбинации значений), возможность сохранить свой пресет и удалить его; хранятся в JSON в данных приложения.
- Реализация: живой предпросмотр через WebGL/Canvas (CSS-фильтры для предпросмотра, финальный рендер в canvas при экспорте — одинаковый результат).

## 5. Архитектура

```
PhotoMaker Studio/
  plan.md
  package.json
  electron/            # main process: окна, диалоги, чтение/запись файлов, меню
  src/
    app/               # оболочка, маршрутизация режимов, тема
    modes/fit/         # режим 1
    modes/collage/     # режим 2
    core/
      formats.ts       # размеры печати, dpi-математика
      image/           # загрузка, HEIC-декодер, canvas-рендер, эффекты
      history/         # undo/redo (команды или снимки состояния)
      project/         # модель проекта, сериализация
      presets/         # эффекты и пресеты
    ui/                # общие компоненты
  assets/stickers/
  tests/
```

- Состояние: Zustand (или Redux Toolkit), история — отдельный слой.
- Холст: Canvas 2D; в режиме коллажа — Konva (react-konva) или собственная реализация; решим на этапе прототипа.
- HEIC: `heic-to` / `libheif-js` в воркере (чтобы не вешать интерфейс).
- Большие фото: даунскейл для предпросмотра, полный размер только при экспорте.
- EXIF-ориентация iPhone учитывается при загрузке.
- Сборка `.app`: `electron-builder` под macOS (arm64, при необходимости universal), без подписи для локального запуска.

## 6. Этапы (MVP → дальше)

1. **Каркас:** репозиторий, Vite + React + TS, Electron, запуск как `.app`, тема, русская локализация (словарь строк), структура папок.
2. **Загрузка фото:** drag & drop, диалог, JPG/PNG/WebP/HEIC, EXIF-ориентация.
3. **Режим 1:** форматы, ориентация, кроп/вписать, dpi-предупреждение, экспорт PNG, пакетный режим.
4. **Эффекты и пресеты:** корректировки, фильтры, встроенные и пользовательские пресеты, undo/redo.
5. **Режим 2, шаблоны:** лист A4, сетки, листы из одинаковых снимков, рамки/паспарту, экспорт.
6. **Режим 2, свободный макет:** перемещение/поворот/слои, тени, скругление, текст.
7. **Стикеры и проекты:** стартовый набор, импорт своих, сохранение/открытие проекта.
8. **Полировка:** горячие клавиши, иконка приложения, сборка `.app`, README.

MVP = этапы 1–4 (подгонка + эффекты). Затем 5–7 (коллажи, стикеры, проекты).

## 7. Тестирование

- Юнит-тесты: размеры форматов, расчёт пикселей и dpi, геометрия кропа, сериализация проекта.
- Проверка экспорта: PNG нужного размера в пикселях, предпросмотр совпадает с результатом.
- Ручная проверка на реальных фото: HEIC и JPG с iPhone (в том числе поворот), два файла из этой папки (скан/фото брошюры).

## 8. Работа с git

- Ветка `main`, рабочие ветки `feature/...`, мелкие коммиты по этапам.
- `.gitignore`: `node_modules`, `dist`, `release`, `*.app`, служебные файлы.
- Фото из корня (`IMG_9334.jpg`, `IMG_9335.jpg`) — референсы, весят около 7 МБ: переносим в `references/` и добавляем в `.gitignore`, чтобы не раздувать репозиторий (если не скажешь иначе).
- Публикация на GitHub только по твоей команде.

## 9. Допущения (скажи, если что-то менять)

- Electron вместо Tauri.
- Формат файла проекта — `.pmstudio` (JSON с изображениями, встроенными как base64 или в папке рядом).
- PDF-экспорт отложен после MVP.
- Метки обрезки на листах из одинаковых снимков — опция, выключена по умолчанию.
- Начальный стикер-набор — векторные SVG, нарисованные нами, без чужих авторских материалов.
- Скриншоты и тексты брошюры Goldbuch используются только как визуальный референс, не копируются в приложение.
