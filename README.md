# PhotoMaker Studio

Локальное приложение для macOS: подгонка фото под печатные форматы (9×13, 10×15, 13×18, A5, 20×30, A4, 10×10, 3×4 и свой размер), эффекты и пресеты, экспорт PNG в 300 dpi. Работает офлайн. Поддерживает JPG, PNG, WebP и HEIC (iPhone).

## Режим «Коллаж»

Лист A4 (книжный или альбомный) с несколькими фото:

- **Два вида листа.** «Страница альбома» — печатаются фон, фото, рамки и тени. «Лист для вырезания» — только фото с рамками на белой бумаге, метки обрезки включены.
- **Шаблоны** на 2, 3, 4 и 6 фото и **лист из одинаковых снимков** (например, 4 × 9×13 или 2 × 10×15): максимум считается с учётом полей (по умолчанию 5 мм) и зазора (4 мм), при нехватке места приложение пишет, сколько помещается.
- **Свободный макет:** перетаскивание, поворот и растяжение мышью, порядок слоёв; у каждого фото рамка (входит в заявленный размер), тень, скругление, кадрирование и эффекты.
- **Фон:** цвет, градиент или текстура (бумага, крафт, грифельная доска).
- **Экспорт:** PNG листа (150–600 dpi, по умолчанию 300) и PDF ровно 210×297 мм с векторными метками обрезки. Печатайте PDF в масштабе 100%, без «вписать в страницу».
- Предупреждения: фото вне безопасного поля, пересечения на листе для вырезания, пустые рамки, мало пикселей для печати.

### Проекты, текст и стикеры

- **Проекты.** «Сохранить», «Как…» и «Открыть…» (⌘S, ⇧⌘S, ⌘O) работают с файлом `.pmstudio`: в него встроены оригиналы использованных фото и импортированные стикеры, поэтому проект открывается на другом Mac. Фото из библиотеки, не стоящие на листе, в проект не попадают. При несохранённых изменениях приложение спрашивает подтверждение при закрытии окна и при открытии другого проекта. Повреждённый или чужой файл не меняет текущую работу.
- **Текст.** «Добавить текст»: шрифт, размер, цвет, выравнивание, жирный/курсив, прозрачность, поворот; строки переносятся по ширине рамки, лишнее обрезается по её границе. Шрифты системные (Bradley Hand, Noteworthy, Snell Roundhand, Marker Felt, Chalkboard SE, Helvetica Neue, Georgia); ничего не скачивается. Если шрифта нет на этом компьютере, подставляется запасной и показывается предупреждение; имя шрифта в проекте сохраняется.
- **Стикеры.** 12 встроенных рисунков (скотч, стрелки, звезда, сердце, ракушка, уголки, штамп, облачко, волна) и импорт своих SVG, PNG, WebP до 5 МБ (PNG и WebP до 4096 px по стороне). SVG со скриптами или встроенными страницами не принимается.
- На «листе для вырезания» текст и стикеры не печатаются, но остаются в слоях; метки обрезки относятся только к фото.
- Не входит: автосохранение, недавние файлы, пакеты стикеров, тень и обводка текста.

## Горячие клавиши

Все сочетания показаны в меню приложения (на русском). Клавиши слоёв не действуют, пока фокус в поле ввода.

| Клавиши | Действие |
|---|---|
| ⌘Z / ⇧⌘Z | Отменить / повторить |
| ⌘O, ⌘S, ⇧⌘S | Открыть проект, сохранить, сохранить как… (режим «Коллаж») |
| ⌘E / ⇧⌘E | Экспорт PNG / PDF (режим «Коллаж»; не запускается, пока экспорт заблокирован или уже идёт) |
| ⌘1 / ⌘2 | Режим «Подгонка» / «Коллаж» |
| Delete или ⌫ | Удалить выбранный слой |
| ← ↑ → ↓, с ⇧ | Сдвинуть слой на 1 мм, с ⇧ на 10 мм |
| ⌘D | Дублировать слой (со сдвигом 5 мм) |
| ⌘] / ⌘[ | Поднять слой выше / опустить ниже |
| Esc | Снять выделение |

Иконка приложения нарисована в `build/icon.svg`; `npm run icon` пересобирает `build/icon.icns` (нужны `sips` и `iconutil` из macOS).

## Команды

| Команда | Что делает |
|---|---|
| `npm install` | Ставит зависимости |
| `npm run dev` | Запускает приложение в режиме разработки (Vite + Electron) |
| `npm test` | Запускает тесты (Vitest) |
| `npm run dist` | Собирает `release/mac-arm64/PhotoMaker Studio.app` (Apple Silicon, без подписи) |

Первый запуск собранного `.app`: правый клик → «Открыть» (приложение не подписано).

## Структура

- `electron/` — главный процесс, мост `window.api`
- `src/core/` — чистая логика без DOM: форматы, dpi, геометрия, рендер, эффекты, история, имена файлов
- `src/modes/fit/` — интерфейс режима «Подгонка»
- `src/modes/collage/` — интерфейс режима «Коллаж»; модель, раскладка, метки и PDF — в `src/core/collage/` и `src/core/export/`
- `docs/superpowers/` — дизайн и планы реализации

Предпросмотр и экспорт используют один и тот же рендерер (`renderFit` для подгонки, `renderCollage` для листа), поэтому результат совпадает с тем, что видно на экране.
