# PhotoMaker Studio

Локальное приложение для macOS: подгонка фото под печатные форматы (9×13, 10×15, 13×18, A5, 20×30, A4, 10×10, 3×4 и свой размер), эффекты и пресеты, экспорт PNG в 300 dpi. Работает офлайн. Поддерживает JPG, PNG, WebP и HEIC (iPhone).

Режим «Коллаж» (лист A4, рамки, стикеры, PDF с метками обрезки) — в следующих планах, см. `docs/superpowers/plans/`.

## Команды

| Команда | Что делает |
|---|---|
| `npm install` | Ставит зависимости |
| `npm run dev` | Запускает приложение в режиме разработки (Vite + Electron) |
| `npm test` | Запускает тесты (Vitest) |
| `npm run dist` | Собирает `release/mac-arm64/PhotoMaker Studio.app` (Apple Silicon, без подписи) |

Первый запуск собранного `.app`: правый клик → «Открыть» (приложение не подписано).

## Структура

- `electron/` — главный процесс, мост `window.api`
- `src/core/` — чистая логика без DOM: форматы, dpi, геометрия, рендер, эффекты, история, имена файлов
- `src/modes/fit/` — интерфейс режима «Подгонка»
- `docs/superpowers/` — дизайн и планы реализации

Предпросмотр и экспорт используют один и тот же `renderFit`, поэтому результат совпадает с тем, что видно на экране.
