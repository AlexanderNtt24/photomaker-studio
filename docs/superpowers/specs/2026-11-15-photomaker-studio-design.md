# PhotoMaker Studio — дизайн

Дата: 2026-11-15. Статус: на согласовании. Расширяет `plan.md` (этапы и допущения оттуда остаются в силе, где не противоречат этому документу).

## 1. Зачем

Автор печатает фото для альбома в стиле скрапбукинга (как в брошюре Goldbuch: небольшие снимки разных размеров, рамки, стикеры, подписи) и хочет удобно выбирать и подгонять фото под нужный печатный размер.

Печать идёт двумя путями, с упором на первый:
1. **Дома на принтере (основной).** Несколько фото разных размеров на листе A4, которые потом вырезаются вручную.
2. **В фотосалоне / онлайн-заказом.** Отдельный файл на каждое фото в точном размере.

Успех: распечатанное фото по размеру совпадает с тем, что на экране и в выбранном формате; лист A4 печатается в масштабе 100% без подгонки; подготовка десятка фото к печати занимает минуты.

## 2. Цели, не цели, антицели

**Цели**
- Режим 1 «Подгонка»: одно или несколько фото под стандартный/свой размер, кроп или «вписать», экспорт PNG точного размера (300 dpi).
- Режим 2 «Коллаж/лист»: лист A4 с несколькими фото, рамками, стикерами, текстом; шаблоны и свободный макет; экспорт PNG и **PDF в точном масштабе с метками обрезки**.
- Эффекты и пресеты (встроенные и свои), на уровне отдельного фото.
- Проекты сохраняются и открываются, undo/redo везде.
- Офлайн, русский интерфейс, системная тема, минималистичный вид.

**Не цели (первая версия)**
- Облако, учётные записи, онлайн-заказ печати.
- Профессиональная цветокоррекция (ICC-профили, CMYK).
- Редактирование пикселей (кисти, слои-маски, ретушь).
- Windows/Linux.

**Антицели (провал, даже если «работает»)**
- Предпросмотр на экране отличается от распечатки или файла.
- PDF при печати «Фактический размер» даёт размеры, отличающиеся от заявленных больше чем на 0,5 мм.
- Потеря работы: закрыл окно — проект пропал без предупреждения.

## 3. Ограничения

- macOS, локальный запуск как `.app` (Electron), Node 26 на машине, Rust нет.
- Стек: React + Vite + TypeScript; Canvas 2D как единый движок рендера; Konva для интерактивного редактирования коллажа; `pdf-lib` для PDF; HEIC декодируется локально (WASM-библиотека) в воркере.
- Никаких сетевых запросов в работе приложения.
- Отдельный git-репозиторий внутри `PhotoMaker Studio` (сейчас корень git — домашняя папка; нужен `git init` в проекте, иначе коммиты попадут в чужой репозиторий).

## 4. Подходы (рассмотрены три)

- **А. Единый движок на Canvas** — сцена описана данными, один рендерер рисует и предпросмотр, и экспорт; Konva только для перетаскивания/поворота; PDF: страница точного размера в мм, изображение листа в 300 dpi, метки обрезки векторные.
- **Б. HTML/CSS + печать Electron** — быстрее старт, но эффекты и размеры в предпросмотре и печати могут расходиться; слабая точность в мм.
- **В. Гибрид** — два пути рисования, расхождения неизбежны.

Выбран **А** (решение автора). Причина: цель — печать, и экран должен совпадать с бумагой.

## 5. Решения автора (по ответам в обсуждении)

- Форматы печати: 9×13, 10×15, 13×18, 15×21 (A5), 20×30, 21×30 (A4), 10×10, 3×4 + свой размер в см/мм; книжная/альбомная; кроп и «вписать».
- 300 dpi по умолчанию, настраивается; предупреждение, если исходник мал.
- Пакетная обработка в режиме 1.
- Коллаж: и сетки-шаблоны, и свободный макет; лист A4; фон, рамки/паспарту, тени, скругление, поворот, текст.
- Стикеры: стартовый набор + возможность добавлять свои.
- Эффекты: ч/б, сепия, винтаж, яркость, контраст, насыщенность, резкость, размытие, виньетка, зерно; пресеты — встроенные и свои; применяются к отдельному фото.
- Ввод: перетаскивание и выбор файла; JPG, PNG, WebP, HEIC/HEIF (iPhone).
- Вывод: PNG; печать на A4 несколькими снимками; **PDF и метки обрезки входят в первую версию** (изменено относительно `plan.md`).
- Проекты сохраняются для последующего редактирования; undo/redo обязательно.
- Русский язык, тема как в системе, минимальный интерфейс; название «PhotoMaker Studio»; git обязателен.
- MVP: подгонка + простые эффекты, затем коллажи, затем стикеры.

## 6. Как работает печать (ключевые требования)

- **Единицы:** внутренняя модель в миллиметрах; пиксели — только при рендере (`px = мм × dpi / 25,4`).
- **Лист A4:** 210×297 мм, при 300 dpi — 2480×3508 px.
- **PDF:** страница ровно 210×297 мм, без масштабирования; пользователю подсказка «печатать в масштабе 100%, без “вписать в страницу”».
- **Метки обрезки:** тонкие линии у углов каждой фотографии, вне её области (с отступом), не заходящие на соседние снимки; включены по умолчанию на листах для печати дома.
- **Поля принтера:** настраиваемые безопасные поля листа (по умолчанию 5 мм); предупреждение, если фото выходит за них.
- **Лист из одинаковых снимков:** авторазмещение (например 4 × 10×15 на A4 с учётом полей и зазоров), с предупреждением, если формат не помещается.
- **dpi-предупреждение:** эффективный dpi по обрезке; мягкое < 300, сильное < 150.
- **EXIF-ориентация** iPhone учитывается при загрузке.

### Два вида листа в режиме 2 (решение автора)

Переключатель «Страница альбома / Лист для вырезания»:
- **Страница альбома:** фон, фото, рамки, стикеры и текст печатаются вместе. Метки обрезки по умолчанию выключены (включаются, если страницу нужно вырезать из A4).
- **Лист для вырезания:** печатаются только фото (с рамкой), без фона, стикеров и текста; метки обрезки у каждого фото включены по умолчанию.
- Один проект можно переключать между видами без потери содержимого; в листе для вырезания неотображаемые слои (фон, стикеры, текст) сохраняются, но не рисуются и не экспортируются.

### Рамка и размер фото (решение автора)

Рамка и паспарту **входят в заявленный размер**: фото 10×15 с рамкой 5 мм занимает ровно 10×15 см, видимая часть кадра при этом уменьшается. Размер на листе и метки обрезки считаются по внешнему краю рамки. Для режима 1 и для листов действует одно и то же правило.

## 7. Модель данных (набросок)

- `Project`: версия формата, режим, лист (размер, ориентация, поля, фон), список слоёв, настройки экспорта.
- `Layer`: фото | стикер | текст; положение и размер в мм, поворот, порядок, рамка/паспарту, тень, скругление, эффекты (`EffectStack`).
- `Asset`: исходное изображение (путь + встроенная копия в проекте), миниатюра для предпросмотра.
- `Preset`: именованный набор значений эффектов; хранятся в данных приложения.
- Файл проекта `.pmstudio` содержит всё нужное, чтобы открыться на другой машине (изображения встроены).

## 10. Допущения исполнителя (проверить автору)

- Метки обрезки включены по умолчанию на «листе для вырезания», выключены на «странице альбома» и при экспорте одиночного фото.
- Безопасные поля принтера по умолчанию 5 мм.
- Зазор между фото на листе по умолчанию 4 мм.
- PNG экспортируется в sRGB; профили не встраиваются.
- Пакетный экспорт сохраняет файлы в выбранную папку с именами `<имя>_<формат>.png`.
